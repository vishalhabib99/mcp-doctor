# Pyodide wheels for the in-browser check

`tree_sitter_typescript-0.23.2-cp39-abi3-pyemscripten_2026_0_wasm32.whl` is
[tree-sitter-typescript](https://github.com/tree-sitter/tree-sitter-typescript)
0.23.2 (MIT license, © Max Brunsfeld and contributors), compiled for Pyodide
314.0.7 because Pyodide doesn't ship it. Built from the v0.23.2 git tag (the
PyPI sdist lacks `tree_sitter/parser.h`) with:

```bash
uv venv --python 3.14 .venv && . .venv/bin/activate && uv pip install pyodide-build
pyodide xbuildenv install 314.0.7
git clone https://github.com/emscripten-core/emsdk && emsdk/emsdk install 5.0.3 && emsdk/emsdk activate 5.0.3
source emsdk/emsdk_env.sh
git clone --depth 1 --branch v0.23.2 https://github.com/tree-sitter/tree-sitter-typescript && cd tree-sitter-typescript
pyodide build -o ../dist
```

`tree_sitter_rust-0.23.3-cp39-abi3-pyemscripten_2026_0_wasm32.whl` is
[tree-sitter-rust](https://github.com/tree-sitter/tree-sitter-rust) 0.23.3
(MIT license, © 2017 Maxim Sokolov), built the same way from its v0.23.3 git
tag. Not 0.24: its grammar is ABI 15 and Pyodide's tree-sitter reads 13-14
("Incompatible Language version 15"). mcp-doctor's Rust results are identical
on both (checked on 18 repos, 2026-10-18).

Rebuild them when the Pyodide version in `worker.js` changes.
`mcp_doctor/` and `manifest.json` here are generated by `../build.py`; don't edit them.
