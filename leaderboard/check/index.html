Check an MCP server

Before your agent connects to a server, see whether it can tell what each tool does, and whether the code has risky patterns. Paste a GitHub repo, an npm package or a PyPI package.

Try: homeassistant-ai/ha-mcp · sooperset/mcp-atlassian · oraios/serena

How this works

This page runs mcp-doctor, the same open-source analyzer as pip install mcp-server-lint, inside your browser. It downloads the repo's source files straight from GitHub and reads them. Nothing is run, nothing is uploaded, and no account is needed.

  • Quality: can an agent tell what each tool does and what to pass? Tool descriptions, parameter docs, error handling, README, tests, license.
  • Security: prompt-injection-prone descriptions, dynamic execution, SSRF-prone requests, unsafe deserialization, hardcoded secrets. Shown as counts only; run the command line version on your own machine for details.

It reads Python, TypeScript and Go servers. Grades are a starting point for a look, not a verdict. A wrong grade? Open an issue; that's how most of mcp-doctor's fixes started.
